# Contributing

Keep the application external and screen-based. Minigame input should remain stationary: press and release the left mouse button, without cursor steering or game injection.

Before submitting a change, run the offline checks and review the affected behavior. Add a meaningful regression check for recognition or input-state fixes. Synthetic examples are preferred; never commit full desktop screenshots, private calibration profiles, logs, credentials, or local absolute paths.

For a recognition issue, describe the stage, game client resolution, Windows display scaling, and application version. If an image is needed, share only a tightly cropped control after checking it for identifying information.

Keep UI text and documentation in English. Preserve profile migration and stop/cancellation behavior. Explain changes in plain language in your pull request.
